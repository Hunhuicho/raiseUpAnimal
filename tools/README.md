# tools

## eyecheck.js

머리 장식이 눈을 가리는지 **실제 렌더링 좌표로** 검사한다.

```
npm i playwright
node tools/eyecheck.js
```

머리 장식 9종 × 동물 8종 = 72가지 조합을 전부 그려보고, 장식의 각 도형이
눈 넓이의 6% 넘게 덮으면 잡아낸다. 안경·선글라스는 눈 위에 얹는 게 정상이라 제외.

**왜 눈으로 안 보고 좌표로 보나** — 종마다 머리 높이 보정값이 달라서
(고슴도치 +36, 금붕어 −18/+12, 거북이 −8) 고양이에서 멀쩡해도 다른 종에서만
겹치는 일이 생긴다. 실제로 꽃 잎사귀와 리본 끈이 그렇게 걸렸다.
