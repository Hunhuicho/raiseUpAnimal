# tools

## eyecheck.js

머리 장식이 눈을 가리는지 **실제 렌더링 좌표로** 검사한다.

```
npm i playwright
node tools/eyecheck.js
```

머리 장식 × 동물 8종을 전부 그려보고, 눈 넓이의 6% 넘게 덮으면 잡아낸다.
안경·선글라스는 눈 위에 얹는 게 정상이라 제외.

**바운딩 박스가 아니라 픽셀로 잰다.** 장식 레이어만 240×240으로 래스터화해서
눈 타원 안쪽의 불투명 픽셀을 직접 센다. 박스로 재면 머리띠처럼 위로 휜 곡선이
눈을 지나가는 것으로 오탐된다 — 헤드폰이 실제로 그렇게 걸렸다.

**왜 눈으로 안 보고 좌표로 보나** — 종마다 머리 높이 보정값이 달라서
(고슴도치 +36, 금붕어 −18/+12, 거북이 −8) 고양이에서 멀쩡해도 다른 종에서만
겹치는 일이 생긴다. 실제로 꽃 잎사귀와 리본 끈이 그렇게 걸렸다.
